# TECHNOLOGY COLOPHON

    ## Architecture & Core
    WordPress 6.4+, tested up to 7.1
    PHP 8.1+ (strict types)
    MySQL: five plugin tables (hash-chained consent register, consent types, their text archive, guardian registry, guardian requests)
    WP-CLI commands, two REST routes and one daily WP-Cron event

    ## Front End
    Three server-rendered shortcodes with one stylesheet (self-hosted, no CDN, no script)
    Admin screen built from the native WordPress admin markup

    ## Quality
    Standalone test suite on SQLite with a mutation check, a rolled-back runtime check in WordPress
